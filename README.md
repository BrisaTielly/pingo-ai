# Tecnologias

Por enquanto, essas são as tecnologias que pretendo usar no projeto:

- **Python:** linguagem principal do backend.
- **FastAPI:** para criar a API que vai receber e responder as mensagens.
- **PostgreSQL:** para salvar os gastos e outras informações necessárias.
- **WhatsApp Cloud API:** integração oficial para enviar e receber mensagens pelo WhatsApp.
- **IA:** para interpretar mensagens como "gastei 30 reais no almoço" e transformar isso em dados organizados.
- **AWS:** para colocar a aplicação no ar futuramente.
- **pytest e GitHub Actions:** para testes e automações conforme o projeto for crescendo.

Essas escolhas ainda podem mudar conforme eu for entendendo melhor as necessidades do projeto.
